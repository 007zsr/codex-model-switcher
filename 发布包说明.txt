Codex 模型切换器－清洁发布包

本发布包不包含 API Key、账号密码、Codex 用户配置、本机路径、日志、历史备份或调试数据。

程序要求用户在自己的电脑上输入第三方 API Key。持久化的 Key 保存在 Windows 凭据管理器中，不保存在程序文件夹内。

清洁打包时排除了：
- data（本机日志、报告、设置与模型验证缓存）
- version-backups（旧版源码、旧 config.toml 和旧运行状态）
- tools 中的调试、探测、预览数据与日志
- switcher-state.ini、settings.ini、launch-hint.ini、config.toml、auth.json
- *.log、*.bak、*.tmp 等运行与临时文件
